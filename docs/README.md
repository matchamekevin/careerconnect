# Documentation CareerConnect

## Structure

Cette dossier contient toute la documentation du projet CareerConnect, organisée par catégories.

### Dossiers

- **`guides/`** - Guides d'utilisation et de dépannage
- **`corrections/`** - Documentation des corrections appliquées
- **`features/`** - Documentation des nouvelles fonctionnalités

### Fichiers principaux

- Configuration et setup
- Système d'email
- Informations de contact
- Résumé des missions

## Guides disponibles

### Guides d'utilisation
- Guide de dépannage des avis
- Guide de configuration Gmail
- Guide d'intégration WhatsApp
- Guide de debugging de login

### Corrections documentées
- Corrections de la page d'avis
- Corrections des domaines d'études
- Corrections des états de sections
- Historique des corrections

### Nouvelles fonctionnalités
- Amélioration du profil étudiant
- Intégration WhatsApp
- Nouvelles fonctionnalités générales

## Utilisation

Consultez les guides selon vos besoins :
- Pour un problème spécifique : `guides/`
- Pour comprendre une correction : `corrections/`
- Pour une nouvelle fonctionnalité : `features/`
