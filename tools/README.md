# Outils CareerConnect

## Scripts et utilitaires

Ce dossier contient les outils et utilitaires du projet :

### Scripts de démarrage

- **`start-app.sh`** - Script de démarrage de l'application complète
- **`start-server.js`** - Script de démarrage du serveur Node.js

### Outils de maintenance

- **`RESUME_FINAL_CORRECTIONS.sh`** - Résumé des corrections finales appliquées

## Utilisation

### Démarrage de l'application
```bash
./tools/start-app.sh
```

### Démarrage du serveur seulement
```bash
node tools/start-server.js
```

### Résumé des corrections
```bash
./tools/RESUME_FINAL_CORRECTIONS.sh
```

## Intégration

Ces outils sont intégrés dans le workflow global du projet et peuvent être appelés depuis d'autres scripts.

## Maintenance

Les outils sont conçus pour être :
- Autonomes
- Réutilisables
- Bien documentés
- Compatibles avec la structure du projet
